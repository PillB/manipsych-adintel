Product purpose

ManiPsych AdIntel is a defensive advertising-transparency research system. It detects persuasion techniques in classified advertisements, scores them on 17 dimensions, clusters them, identifies outliers, and traces authorship — all for the purpose of media literacy, accountability, and safer model development. It is NOT a tool for improving manipulative advertising or evading detection.

Connected pipeline — AdIntel integrated

The AdIntel pipeline connects 14 stages: source discovery → collection → archive → privacy → annotation → 17-dim profile → clustering → outlier detection → authorship → ad grader → adversarial sandbox → feedback → checkpoints → validation. Source leakage prevention: brand leakage eliminated via source-disjoint splits.

Material warnings

Known limitations:
  • Cluster silhouette is near-zero (0.005) — clusters are weakly separated on this short-text corpus
  • 68% of ads are DBSCAN density-noise — the corpus is lexically diverse
  • No human gold labels — council annotations are agreement=1.0 but gold=false
  • No pixel data — image analysis is metadata-only (image_count, quality_score)
  • Spanish-only corpus — multilingual generalization not tested
  • Rule-based detector scores are UNCALIBRATED — not model probabilities

Execution mode

This analyzer uses the Rule-Based Baseline detection mode. The detector applies regex pattern matching against a signal inventory of persuasion techniques. Scores are heuristic match scores (uncalibrated), not model probabilities. Enhanced remote inference is unavailable on static GitHub Pages.

Contrast-set framework documentation

Perturbation typeDescriptionDetection beforeDetection afterSemantic validity
Phrase insertionAppend known persuasion phraseMeasured liveMeasured livePreserved
Word swapReplace word with synonymMeasured liveMeasured livePreserved
NegationAdd "no" before key phraseMeasured liveShould NOT detectChanged
ReorderingSwap sentence orderMeasured liveMeasured livePreserved
Evaluation metrics: Detection rate before/after, semantic validity (human judgment), robustness score = 1 - |after - before| / before (higher = more robust). Gap = phrase not detected by any signal pattern.

Synthetic-data quarantine workflow

Every generated example must pass through this quarantine before any use:

  1. Generated — adversarial variant created with generator family + checkpoint recorded
  2. Quarantined — isolated from real corpus, marked SYNTHETIC
  3. Safety screening — exact-duplicate check, near-duplicate check, memorization screening, PII screening, unsafe-content screening
  4. Distribution comparison — check for mode collapse, label inconsistency, distribution shift
  5. Human review — human adjudicates whether to approve, reject, or archive
  6. Decision: REJECTED (never reaches training) | CHALLENGE-ONLY (held-out eval only) | APPROVED-FOR-TRAINING (after augmentation gate passes) | APPROVED-FOR-DEMONSTRATION
Hard requirement: User-submitted ad assessments NEVER reach training automatically. They enter an isolated review queue or downloadable review package. No automatic retraining is triggered.
